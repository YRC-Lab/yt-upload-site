Who uses this app

yt-upload is a personal tool. Its only user is its developer, who authorizes it with their own Google account. No other person is asked to sign in.

Google user data accessed

With the scope https://www.googleapis.com/auth/youtube.force-ssl, the tool accesses the developer's own YouTube channel to: upload videos, upload caption tracks, read and update video descriptions and settings, and read and add playlist items.

How the data is used and stored

  • The OAuth token is stored only as a file on the developer's own computer and is never transmitted to any server operated by the developer.
  • The developer operates no server and no database for this app, and collects no analytics.
  • Video metadata that the tool reads is used only to perform the actions above and is not kept beyond local log files and description backups on the developer's own computer.

Sharing

The app does not sell, share, or transfer Google user data to any third party. The one outbound use: to generate chapter markers, the subtitle text of the developer's own video may be sent to an AI model API chosen by the developer (for example Google's Gemini API). That text is the developer's own content and is handled under that provider's API terms.

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions, and by deleting the local token file.
